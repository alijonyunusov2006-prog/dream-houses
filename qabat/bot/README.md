# Бот Qabat для клиентов

Telegram-бот: клиенты пишут ему, он отвечает через бесплатную модель на ПК (Ollama, RTX 3090).
Всё, что пишут клиенты, приходит владельцу в группу «Qabat — заявки». Для каждого клиента там своя тема.

**Статус:** код готов, проверен тестами без интернета (`python -m pytest qabat/bot/tests -q`).
С настоящим Telegram и моделью на ПК бот **ещё не проверен**.

## Что умеет
- Отвечает клиенту коротко, на его языке (русский или таджикский). Знает каталог из `qabat/kit/data.py`.
- **Цены не называет**, пока владелец их не утвердил. Если модель всё же напишет цену, код вырежет её и ответит «Цену уточнит мастер».
- Не пишет «готово», не просит предоплату, не обещает скидок.
- Сразу передаёт мастеру:
  - жалобы;
  - опт от 30 штук;
  - восстановление деталей;
  - «как на картинке» и макеты;
  - фото, голосовые и файлы;
  - сообщения, на которые модель не ответила.
- **Владелец отвечает сам:** пишет в теме клиента, и сообщение уходит клиенту от имени бота. После этого бот молчит.
  - `/bot` в теме — снова отвечает бот.
  - `/me` — бот молчит, отвечаете вы.

## Запуск на ПК
1. В BotFather сделайте `/revoke` и получите новый ключ. Старый ключ остался в переписке.
2. Создайте группу «Qabat — заявки». Включите в настройках группы «Темы». Добавьте бота админом с правом «Управление темами».
3. Напишите в группе `/id`. Бот ответит номером группы.
4. Впишите переменные в `jarvis/config/.env` на ПК (не в Git):
   ```
   QABAT_TG_BOT_TOKEN=<новый ключ>
   QABAT_OWNER_CHAT_ID=<номер группы>
   ```
5. Модель: `ollama pull` той модели, которую выбрал владелец по `проверка-модели.md`. Имя модели — в `QABAT_MODEL`, по умолчанию оно берётся из `jarvis/config/settings.toml`.
6. Из корня репозитория: `python -m qabat.bot`.
7. Проверка: напишите боту с другого аккаунта 10 сообщений из `задание-пк-бот-модель.md` и посмотрите темы в группе.

Работает, пока включён ПК. Для Telegram публичный адрес не нужен. Instagram Direct подключим позже, через Meta и туннель.
