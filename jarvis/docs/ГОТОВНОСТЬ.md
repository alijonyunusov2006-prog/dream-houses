## Работает и проверено вживую
| Что | Как проверено |
|---|---|
| Запуск с ярлыка и сам при входе в Windows | ярлык в «Автозагрузке»; окно режима Джарвиса на весь экран + живой JARVIS сверху |
| Слово «Джарвис» и голос | «Джарвис, я дома» голосом → доклад; чужая речь без «Джарвис» выбрасывается |
| Голос ESpeech, без акцента | доклад озвучивается за ~5 с, распознавание его же речи — все слова верно |
| Разговор без задач | «ты здесь?», «повтори», «спасибо», «что умеешь», «стоп», «не надо, номер 14», «Конец.» — мгновенные ответы |
| Вопросы | «где лежит…», «сколько…?» — короткий ответ без отчёта |
| Счёт, перевод, время | локальная модель на видеокарте, 1–2 с, бесплатно |
| Задания | «Вот что я понял» → «Делает: Контент» → агент делает → отчёт (проверено: 3 идеи для поста, 2 мин) |
| Рискованное | удаление, деньги, сообщения людям — только после «да» |
| Память | «Вспомни, что решили про голос» → ответ из заметок и второго мозга, без разметки |
| Идеи | «Идея: …» → записано во второй мозг |
| До 3 задач сразу | проверено двумя настоящими задачами одновременно |
| Лимит подписки | говорит по-русски, до скольки; задачи ждут и начинаются сами после сброса |
| 3D-офис | кнопка «Офис» или «Джарвис, покажи офис»: 23 агента + JARVIS (зелёный — работает, янтарный — ждёт вас, серый — свободен), 16 проектов из второго мозга, здоровье ПК; поле «Скажите Джарвису» отдаёт задание настоящему JARVIS и показывает ответ. Проверено: задача про рилс — на макете загорелся «Контент» |
| Защита | окно и офис доступны только с этого ПК; ключи — только в `.env`; пароли, токены, логины, почта и телефоны в офис не попадают; 3D-библиотека лежит на ПК, из интернета код не грузится |
| Проверки кода | 202 автоматические проверки — все зелёные; независимое ревью — критичного нет, важное исправлено |
