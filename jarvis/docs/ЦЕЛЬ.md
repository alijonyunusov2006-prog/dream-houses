## Слушается
- [x] Разговор не становится задачей: «ты здесь», «спасибо», «повтори», «что умеешь», шум из одного слова.
- [x] «Стоп» в любой форме: «стоп», «да стоп же», «стоп, я сказал», «хватит», «остановись», «прекрати», «не надо»,
      «отменяю 14», «отмени задачу 15», «отмени всё» — отменяет, а не заводит задачу.
- [x] «Замолчи» / «тихо» — сразу обрывает его голос в окне.
- [x] Ругань в адрес JARVIS не становится задачей и не ломает «стоп».
- [x] Задание во время лимита: честно «записал №N, начну в 22:10», без «повторить?» и без английских ошибок.
