## Слушается
- [ ] Разговор не становится задачей: «ты здесь», «спасибо», «повтори», «что умеешь», шум из одного слова.
- [ ] «Стоп» в любой форме: «стоп», «да стоп же», «стоп, я сказал», «хватит», «остановись», «прекрати», «не надо»,
      «отменяю 14», «отмени задачу 15», «отмени всё» — отменяет, а не заводит задачу.
- [ ] «Замолчи» / «тихо» — сразу обрывает его голос в окне.
- [ ] Ругань в адрес JARVIS не становится задачей и не ломает «стоп».
- [ ] Задание во время лимита: честно «записал №N, начну в 22:10», без «повторить?» и без английских ошибок.
- [ ] Лимит кончился посреди работы — продолжает сам после сброса.

## Говорит
- [ ] Голос ESpeech в окне и голосовыми в Телеграме; служебное — только текстом.
- [ ] Числа словами, без английских слов, коротко вслух — подробно на экране.
- [ ] Доклад «я дома» — что сделано, что в работе, что ждёт.

## Работает
- [ ] Каждой задаче — агент («Делает: Контент»), отчёт без разметки.
- [ ] Вопросы — короткий ответ без отчёта на пять пунктов.
- [ ] Счёт, перевод, время — локально за 1–2 с.
- [ ] Память «вспомни…» — чисто, без таблиц.
- [ ] До 3 задач сразу; не больше двух напоминаний.
