# ADR-0004. Срочная связь: сообщение → 5–10 минут → звонок

**Дата:** 2026-09-27 · **Статус:** принято; звонки — исследование этапа 7

## Решение
Срочное уточнение: JARVIS пишет в Telegram с пометкой «срочно»; нет ответа `escalation_minutes` (по умолчанию 10) —
звонит. До реализации звонков — повторное сообщение и голосовое сообщение.

## Варианты звонков
1. Telegram-звонок с второго аккаунта владельца (MTProto, NTgCalls) — бесплатно, серая зона надёжности; исследуем первым.
2. Обычный телефонный звонок через Twilio — надёжно, платно (~0.05 $/мин + номер) — только с согласия.
3. Голосовое сообщение в Telegram + push — резерв, работает всегда.
