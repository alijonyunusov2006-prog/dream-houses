# ADR-0003. Одна папка, второй мозг — Obsidian-vault, правила трёх уровней

**Дата:** 2026-09-27 · **Статус:** принято

## Решение
Весь JARVIS — один репозиторий: код, агенты, навыки, `brain/`. `brain/` открывается в Obsidian.
Правила: `always.md` / `decided.md` / `always-ask.md`; вопросы — `00-inbox/questions.md`; ошибки — `90-lessons/`.

## Почему
Владелец хочет «спросил один раз → стало правилом» и накопление опыта за год. Файлы в Git дают историю,
читаемость человеком и отсутствие зависимости от сервисов.
