# ADR-0001. Ядро на Python, мозг — Claude Code через headless CLI

**Дата:** 2026-09-27 · **Статус:** принято

## Контекст
ТЗ требует управляющего агента с разрешениями, планировщиком ресурсов и облачной очередью. OpenJarvis даёт
инфраструктуру, но не эти функции; его `ClaudeCodeAgent` требует API-ключ.

## Решение
Свой пакет `core/jarviscore` (без внешних зависимостей). Claude Code вызывается как `claude -p --output-format json`
(штатный программный режим CLI), работает по подписке Max. OpenJarvis подключается как библиотека.

## Последствия
+ Полный контроль над политикой и очередью; тесты без сети; подписка вместо оплаты токенов.
− Нужен установленный Claude Code и `claude login` на ПК; лимиты окон подписки надо уважать (стоп-кран).
