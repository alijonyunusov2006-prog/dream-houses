# ADR-0002. Облачный шлюз на Vercel + Supabase

**Дата:** 2026-09-27 · **Статус:** принято (ждёт подтверждения владельца по расходам — бесплатные тарифы)

## Контекст
Задания должны приниматься, когда ПК выключен. Владелец уже использует Vercel и Supabase (CRM), оба подключены.

## Решение
Вебхук Telegram — функция на Vercel; очередь — схема `jarvis` в Supabase; локальный агент опрашивает очередь и шлёт пульс.
Голосовые расшифровывает ПК (есть GPU), шлюз хранит `file_id`.

## Альтернативы
VPS ≈ 5 $/мес (постоянный процесс, проще отладка) — отклонено до появления потребности.
