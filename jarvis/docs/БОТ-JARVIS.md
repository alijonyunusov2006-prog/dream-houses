# Бот JARVIS в Telegram — как включить

Личный бот владельца (не бот Qabat). Работает на ПК, облако не нужно. Пока ПК выключен, Telegram хранит
сообщения сутки — после включения бот их заберёт.

## Что умеет сейчас
- Текст или **голосовое** → «🎙 Расслышал: …» (распознавание на ПК, бесплатно) → задача с номером.
- «**Вот что я понял**» по каждой задаче → вопросы, если без них нельзя начать → выполнение → отчёт.
- Рискованное (деньги, удаление, публикации, сообщения людям, аккаунты, печать, выключение ПК) — только после «да».
- «**Идея: …**» — не задача, а запись во второй мозг (`brain/05-ideas/<дата>-telegram.md`).
- **Контролёр**: вопрос без ответа 10 минут → «Срочно…» и повтор раз в час (звонок — следующий шаг);
  задача в работе без движения 90 минут → предупреждение; срок горит → предупреждение.
- Команды: `/tasks` — открытые задачи, `/cancel N` — отменить №N, `/help`, `/id`.
- На вопросы бота отвечайте **ответом на его сообщение** (свайп влево по сообщению).

## Включить (один раз, делает владелец)
1. В Telegram откройте **@BotFather** → `/newbot` → имя «JARVIS» → короткое имя, например `alijon_jarvis_bot`.
   BotFather пришлёт ключ — длинную строку с двоеточием. **Никому её не пересылайте и не пишите в чат с Claude.**
2. На ПК откройте папку `C:\Jarvis\dream-houses\jarvis`, создайте файл `.env` (если нет) и впишите строку:
   `TELEGRAM_BOT_TOKEN=<ключ из BotFather>`
3. Запустите `Запустить-бота.cmd` (двойной щелчок). Откроется чёрное окно «JARVIS запущен».
4. Напишите своему боту в Telegram `/id` — он ответит номером чата.
5. Впишите в тот же `.env` вторую строку `OWNER_CHAT_ID=<номер>`, закройте окно бота и запустите снова.
   С этого момента бот слушает **только вас**; сообщения от других людей он молча пропускает.

## Где что лежит
- Код: `core/jarviscore/bot.py` (бот), `controller.py` (контролёр), `stt.py` (голос), `telegram.py`.
- Задачи: `data/tasks.json` · журнал: `data/logs/bot.log` · расходы Claude: `data/logs/costs.jsonl`.
- Тесты: `python -m pytest -q` в папке `jarvis`.

## Ограничения (честно)
- Окно бота должно быть открыто; автозапуск при включении ПК — следующий шаг.
- Задачи выполняются по одной (несколько сразу — задача 5).
- Звонков ещё нет: вместо звонка — повторное сообщение «Срочно».
