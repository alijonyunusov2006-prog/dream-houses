# Qabat — ведение Instagram силами JARVIS (2026-10-05)

Владелец хочет: «ты сам ведёшь Instagram, мне — отчёт, решаю только важное».

## Что JARVIS может сам (после подключения через Windsor.ai)
Проверено через `list_actions` для `instagram` 2026-10-05. Доступно:
- публикации: фото, карусели 2–10 фото, Reels;
- истории (фото или видео 3–60 с);
- комментарии: ответить, скрыть, удалить.
Плюс чтение статистики для отчётов.

Требования:
- картинки — JPEG до 8 МБ по публичной ссылке, соотношение сторон от 4:5 до 1,91:1, у историй 9:16;
- публичные ссылки — файлы в публичном репозитории (`raw.githubusercontent.com/...`).

Подключение:
- ссылка https://onboard.windsor.ai/connect?connector=instagram&next=/instagram/authorize — владелец входит сам, пароль в чат не присылает;
- сначала аккаунт должен стать бизнес-аккаунтом и быть связан со страницей Facebook (шаги 3 и 9 настройки).
Если Windsor попросит оплату за второй аккаунт — без «да» владельца не подключаем.

## Что делает только владелец в приложении
Instagram не даёт это никакой программе:
- «Актуальное» и обложки;
- имя, описание, аватарка, ссылки, кнопки;
- закрепление публикаций;
- добавление истории в раздел «Актуального».
Делается один раз, ~15 минут, по странице https://claude.ai/artifact/TYxaDRmmtiauBLB3zPXVGF. Потом, когда JARVIS выложит историю, владелец только нажимает «В актуальное».

## Что нужно от владельца для контента
- **Фото и видео настоящих изделий** — JARVIS их не придумывает и не генерирует под видом настоящих.
- JARVIS делает сам: подписи, карточки с ценами, карусели «Как заказать», истории разделов, обработку фото, план и расписание.

## Правило публикаций — ждёт решения владельца
По `always-ask.md` публикации подтверждаются каждый раз. Владелец хочет больше самостоятельности.
Предложение JARVIS: **одно «да» на недельный план** (список публикаций с картинками и подписями). Дальше JARVIS выкладывает по расписанию и шлёт отчёт.
Ответы на комментарии:
- обычные («цена?», «где вы?») — сам, по шаблонам;
- жалобы и споры — сначала владельцу.
Пока владелец не сказал «да» — каждую публикацию подтверждать.

## 2026-10-05: у владельца нет Facebook
Владелец заведёт Facebook, свяжет с Instagram Qabat и даст доступ через Windsor. Порядок:
1. Личный аккаунт — на настоящее имя владельца, не «Qabat»: Facebook блокирует личные аккаунты-бренды. Фото и двухфакторная защита.
2. Страница «Qabat — 3D-печать», категория «Товары/услуги».
3. Instagram → «Страница» → «Подключить существующую».
4. Ссылка Windsor → войти этим Facebook → выбрать только Qabat.
После «подключил» — JARVIS проверяет `get_connectors`, ничего не публикует без «да».
