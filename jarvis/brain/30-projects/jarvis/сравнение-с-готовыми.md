## Решение (предложение)
Ядро оставить наше. Не скачивать чужой проект целиком: ни один не умеет нашу связку, а замена = потеря Telegram,
контролёра, безопасности и тестов. Добавлять куски по очереди, каждый с тестами:
1. Слово «Джарвис» (openWakeWord) + русский голос (Silero/Piper) — самый заметный эффект.
2. Утренний отчёт по расписанию (образец OpenJarvis/Hermes).
3. Поиск по памяти (mem0 или по Obsidian).
4. Параллельные задачи (своё, идея vierisid).
5. Простые задачи — на локальную модель.
