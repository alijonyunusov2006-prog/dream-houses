# 2026-10-04 · Логотип нарисовал сам вместо навыков владельца

**Что случилось.** Для Qabat я нарисовал шесть логотипов кодом. Владельцу не понравился ни один. Он спросил: «Почему я добавлял эти навыки, если ты их не используешь?»

**Почему.** Не проверил, какие навыки и подключения у владельца уже есть для дизайна, и пропустил шаг «сначала спросить и собрать брендбук».

**Как теперь.**
1. Перед любой творческой задачей — посмотреть навыки владельца и подключения (`skills/CATALOG.md`): для бренда — `personal-brandbook`, для картинок и логотипов — `image-prompt-engineer` + генерация в Higgsfield, для чистового вектора — Figma, для постеров — `canvas-design`.
2. Порядок для бренда: вопросы по блокам → текст брендбука → утверждение → логотип через генерацию → выбор → вектор в Figma.
3. Самодельный код — только если готового навыка нет, и владельцу сказать об этом заранее.
