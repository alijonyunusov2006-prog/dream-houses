# brain/ — второй мозг JARVIS

Откройте эту папку в **Obsidian** («Open folder as vault»). Всё здесь — обычный Markdown,
его читают и вы, и JARVIS. Он пишет сюда сам: вопросы, решения, карточки проектов, дневник.

| Папка | Что там |
|---|---|
| `00-inbox/` | вопросы JARVIS к вам (`questions.md`) и расшифровки ваших голосовых |
| `10-rules/` | правила трёх уровней: `always.md` · `decided.md` · `always-ask.md` |
| `20-me/` | кто вы, бизнесы, стиль, расписание, контакты |
| `30-projects/<имя>/` | ТЗ.md · план.md · решения.md · статус.md · журнал.md |
| `40-clients/` `50-suppliers/` | клиенты и поставщики студии |
| `60-content/` | голос бренда, контент-планы, статистика |
| `70-3d-print/` | заказы на печать: ТЗ, проверки, файлы |
| `75-crm/` | схема и заметки по вашей CRM |
| `80-howto/` | как вы делаете вещи — сырьё для будущих навыков |
| `90-lessons/` | ошибки → правила |
| `daily/` | дневник: что JARVIS сделал за день |

Ссылки между заметками — `[[имя заметки]]`. Плагины не обязательны; удобны Dataview и Templater.
