# Идеи владельца

Владелец присылает мысли в любое время: голосом, текстом, в Telegram. Он сам говорит: «всё, что придумываю, забывается».
JARVIS ловит каждую идею (навык `skills/idea-inbox`), записывает сюда файлом по дате и раскладывает: проект → задачи → день.
Ничего не теряется и не выбрасывается без «да» владельца.
