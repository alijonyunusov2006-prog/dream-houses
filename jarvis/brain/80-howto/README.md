# Как я делаю вещи

Сюда владелец (голосом, JARVIS расшифрует) рассказывает, как он делает работу руками: «планировку из фото делаю так…»,
«отчёт для брата выглядит так…», «в 3ds Max для печати выставляю так…». Из этих заметок JARVIS собирает навыки в `skills/`.

Одна заметка — один процесс. Формат: цель → шаги → что считать хорошим результатом → типичные ошибки.

## Как отдать владельцу файлы из Higgsfield, когда сеть сессии закрыта
1. `media_upload` с именем `.zip` → upload_url и постоянный url.
2. `sandbox_exec`: скачать результаты curl, обработать (ImageMagick, ffmpeg), `zip`, тем же вызовом PUT на upload_url с заголовками Content-Type и If-None-Match: *.
3. `media_confirm` с типом file → дать владельцу постоянную ссылку.
Просмотреть картинки самому — `image_paths` в `sandbox_exec`.
