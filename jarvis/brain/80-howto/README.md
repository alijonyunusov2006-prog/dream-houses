# Как я делаю вещи

Сюда владелец (голосом, JARVIS расшифрует) рассказывает, как он делает работу руками: «планировку из фото делаю так…»,
«отчёт для брата выглядит так…», «в 3ds Max для печати выставляю так…». Из этих заметок JARVIS собирает навыки в `skills/`.

Одна заметка — один процесс. Формат: цель → шаги → что считать хорошим результатом → типичные ошибки.
