## 3. Риски и ограничения, которые надо знать до старта

1. **Нативная сборка на Windows.** OpenJarvis собирает Rust-расширение локально; наш установщик
   ставит Build Tools и Rust, но первая сборка занимает 10–30 минут и может упасть на слабом ПК.
   Запасной путь: WSL2 (официально «рекомендуемый» разработчиками).
2. **Подписка Claude ≠ API.** Agent SDK и `ClaudeCodeAgent` требуют API-ключ (оплата по токенам).
   Headless-режим Claude Code (`claude -p`) работает по подписке — на нём строим раннер.
   У подписки есть лимиты по окнам времени; при исчерпании Jarvis должен ждать, а не падать.
3. **Доступ к файлам.** Инструменты OpenJarvis без ограничения папок. До этапа 5 они включаются
   только внутри нашего слоя разрешений.
4. **Instagram.** Официальный Messaging API доступен только бизнес-аккаунтам через одобренное
   приложение. Обход через браузер не делаем (ТЗ §8).
5. **Telegram-звонки** через пользовательский аккаунт — серая зона надёжности; голосовые сообщения
   как основной канал, звонки как эксперимент этапа 7.
6. **3D-печать.** Программная проверка модели ≠ проверка печати; отчёты формулируем именно так.
