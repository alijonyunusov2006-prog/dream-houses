# AGENTS.md — карта агентов JARVIS

Кто за что отвечает, чтобы ничего не путалось. Один агент — одна область, свои навыки, свои
инструменты. Исполняемые определения лежат в `.claude/agents/<имя>.md` (их читает Claude Code),
навыки — в `skills/<имя>/`. Этот файл — карта для людей и для любого другого ИИ-инструмента,
который понимает стандарт AGENTS.md.

## Управляющий

| Агент | Модель | Делает | Никогда не делает |
|---|---|---|---|
| **JARVIS** (оркестратор, `CLAUDE.md`) | Opus | «Вот что я понял» → ТЗ → план → раздаёт агентам → проверяет → отчёт | не пишет код сам, не верит «готово» без проверки, не делает опасного без подтверждения |

## Правила совместной работы

1. JARVIS ставит задачу одному агенту одной строкой цели + ссылка на карточку проекта. Агент не берёт чужую область: developer не публикует контент, content не трогает CRM.
2. Каждый агент заканчивает отчётом по форме (`core/jarviscore/report.py`). Без данных/файлов/скриншотов отчёт не принимается.
3. Результат developer всегда проходит через tester. Результат archicad/3d проверяется данными модели.
4. Параллельно работают агенты, не делящие ресурсы (`gpu`, `printer:*`, `claude`) — решает планировщик задач.
5. Ошибки агентов → `brain/90-lessons/`. Три ошибки подряд → вопрос владельцу.
6. Новый агент = новый файл в `.claude/agents/` + строка здесь + при необходимости навык в `skills/`.

## Как добавить агента

```
.claude/agents/<имя>.md      ← шапка: name, description, tools, model; тело: правила и порядок работы
skills/<имя>/SKILL.md        ← если нужны длинные инструкции, установка инструментов, тесты
AGENTS.md                    ← строка в таблицу выше
```
