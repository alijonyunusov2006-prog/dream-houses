# Каталог возможностей JARVIS

Что Jarvis будет уметь, откуда это берётся и на каком этапе появляется. Четыре источника:

| Метка | Значение |
|---|---|
| **готовое** | есть на GitHub или уже подключено — ставим и настраиваем |
| **доработать** | готовое есть, но под вашу работу нужно дописать правила/обвязку |
| **создаём** | готового нет — пишем сами (код + навык) |
| **учите показом** | вы объясняете голосом, как делаете руками; Jarvis записывает в навык и проверяет на примере (`skills/learn-from-owner`) |

Статус: ✅ есть в репозитории · 🔄 в работе · ⏳ запланировано. «Есть» означает «написано и проверено тем, чем можно проверить в облаке»; на вашем ПК всё проверяется заново.

## Инструменты памяти и подключения (2026-10-04, по просьбе владельца)
| Инструмент | Зачем | Источник | Статус |
|---|---|---|---|
| **Obsidian** | мозг JARVIS (`brain/`) — это хранилище Obsidian: открыть папку как vault | obsidian.md | ставим на ПК |
| **Graphify** | превращает мозг, проекты, PDF и снимки в карту связей и страницу графа; экономит токены: JARVIS читает граф, а не все файлы | `pip install graphifyy`, навык `/graphify` (github.com/safishamsi/graphify) | ставим на ПК, проверить код |
| **MCP Tools for Obsidian** | ваш Claude (приложение, Cowork) читает и пишет мозг JARVIS | плагин Obsidian + локальный MCP-сервер | ставим на ПК |
| **3dsmax-mcp** | Claude управляет 3ds Max: сцена, MAXScript, Python, шейдеры | Oğulcan Sarıca, GitHub | ставим на ПК, проверить код |
| **3dsmax-rendering** | навык настройки V-Ray и Corona для архвиза | TerminalSkills/skills | ставим на ПК, проверить код |
| Навык `archviz-3dsmax` | порядок архитектурной визуализации студии | `skills/archviz-3dsmax` | создан |

Чужие навыки и серверы ставим только после чтения кода: они получают доступ к ПК.
Все навыки и подключения JARVIS должны быть доступны и вашему Claude: через MCP Tools for Obsidian (мозг) и общие навыки аккаунта.
