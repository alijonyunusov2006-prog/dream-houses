# Библиотека навыков

Навык = папка `skills/<имя>/`:

```
skills/<имя>/
├── SKILL.md        имя, назначение, инструменты, инструкции, ограничения и разрешения, условия успеха
├── tests/          сценарии проверки (что подать на вход → что должно получиться)
└── CHANGELOG.md    история изменений: дата, что поменяли, почему
```

Формат `SKILL.md` — стандарт agentskills.io (YAML-шапка `name`, `description`, опционально `allowed-tools`),
его понимают и Claude Code, и OpenJarvis (`jarvis skill install`).

Правила:
- Новый навык рождается из `brain/80-howto/` или из разговора («Джарвис, научись…»).
- Перед использованием на рабочем проекте — прогон `tests/` на тестовом примере.
- Если навыку нужен код — модуль пишет агент `developer` в `core/jarviscore/skills_ext/<имя>/`, навык ссылается на него.
- Шаблон: `skills/_template/`.
