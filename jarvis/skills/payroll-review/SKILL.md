# Оплата сотрудников

Исполнитель — агент `finance`. **Конфиденциально.** В DH OS раздел «Зарплаты» видит только руководитель — так же и здесь.

## Когда
Только когда владелец сам попросил. Перед началом — одна фраза: «Сделаю разбор оплаты по <период>. Результат пришлю только вам. Начинать?»

## Что сравниваем по каждому сотруднику (за 3 месяца)
- Оплата: оклад, проценты, доли — из DH OS.
- Результат: закрытые задачи, доля в сданных проектах, выручка проектов, где он участвовал.
- Качество: сроки (вовремя / просрочки), возвраты на доработку.
- Нагрузка: сколько задач и проектов одновременно.
- Рынок: вилка оплаты такой роли в Душанбе (открытые вакансии; источник и дата).

## Результат
Таблица: сотрудник, роль, оплата, результат на 1 сомони оплаты, отклонение от рынка, вывод «переплата / норма / недоплата» и **почему**.
Рядом — что сделать: поговорить, пересмотреть процент, дать рост, обучить. Решение — только владельца.

## Нельзя
Отправлять результат кому-либо кроме владельца, писать в общий чат, утренний отчёт, 3D-офис. Делать выводы без данных: мало данных — так и написать.
