# Идеи владельца

1. Записать идею словами владельца в `brain/05-ideas/<дата>-<тема>.md`. Не сокращать смысл.
2. Ответить «Вот что я понял»: одна строка на идею.
3. Разложить: в какой проект (`brain/30-projects/`), какие задачи, кому из агентов.
4. Предложить план на день или на несколько дней: не больше трёх главных задач на день.
5. Утвердить у владельца, потом поставить в очередь.
6. Раз в неделю — сводка: какие идеи сделаны, какие ждут, какие устарели. Удалять только по правилу удаления.
