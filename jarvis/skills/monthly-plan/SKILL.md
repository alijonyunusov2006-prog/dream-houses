# План месяца

Исполнитель — агент `finance`, контент и реклама — `marketolog`, `targetolog`, `screenwriter`.

## Шаги
1. Спросить у владельца одно число: **целевую чистую прибыль месяца** в сомони (или цель по договорам).
2. Взять из DH OS за последние 3 месяца: средний чек, долю прибыли с договора, конверсии заявка → встреча → договор, постоянные расходы. Из Windsor.ai — цену заявки. Нет цифры — спросить владельца, не подставлять «типичную».
3. Посчитать `core/jarviscore/bizplan.py`: `plan_for_profit(...)` → договоры, встречи, заявки, бюджет рекламы.
4. Передать `marketolog`: сколько заявок нужно и из каких каналов; он ставит задачи сценаристу и таргетологу.
5. Показать владельцу одной страницей: цель → договоры → встречи → заявки → реклама → контент-план. Утвердить.
6. Каждый понедельник — `plan_vs_fact(...)`: где отстаём и что сделать на этой неделе.

## Нельзя
Включать рекламу и тратить деньги без «да». Выдумывать конверсии. Показывать зарплаты в плане.
