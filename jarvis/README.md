# Jarvis для Windows — установка одним запуском

Это установщик **OpenJarvis** (https://github.com/open-jarvis/OpenJarvis) — локального ИИ-ассистента,
который работает на вашем компьютере. Установщик ставит всё необходимое, создаёт ярлык «Jarvis»
на рабочем столе и добавляет Jarvis в автозагрузку Windows.

## Что нужно

| | Минимум | Рекомендуется |
|---|---|---|
| Windows | 10 (1809) или 11, 64-бит | Windows 11 |
| Память | 8 ГБ | 16 ГБ и больше |
| Место на диске C: | 6 ГБ | 12 ГБ и больше |
| Интернет | есть | без лимита трафика: скачается 5–7 ГБ |
| Время | 30 минут | до часа на первой установке |

Права администратора нужны только для двух шагов (Git и инструменты сборки C++): Windows сама
покажет окно «Разрешить внесение изменений?» — нажмите **Да**.

## Как установить

1. Скачайте папку `jarvis` (два файла: `Установить-Jarvis.bat` и `install-jarvis.ps1`) в любое место,
   например на рабочий стол.
2. Дважды щёлкните **`Установить-Jarvis.bat`**.
3. Ждите надписи **«Готово. Jarvis установлен.»** Окно не закрывайте.
4. Jarvis откроется сам. При первом запуске он спросит, какой движок использовать — выберите
   **Ollama** (локально, бесплатно, данные не уходят в интернет).

Если что-то пошло не так — просто запустите `.bat` ещё раз. Готовые шаги пропускаются.

## Что именно ставится

| Шаг | Что | Зачем |
|---|---|---|
| Python 3.13 | язык, на котором написан Jarvis | обязателен |
| Git | скачивает исходники Jarvis и обновления | обязателен |
| Visual Studio Build Tools (C++) | компилятор Microsoft, ~3–4 ГБ | без него не собирается нативный модуль Jarvis (память, безопасность) |
| Rust 1.88 | второй язык Jarvis | то же самое |
| uv | быстрый менеджер пакетов Python | ставит зависимости |
| OpenJarvis (исходники) | `%LOCALAPPDATA%\OpenJarvis\src` | сам Jarvis |
| Ollama | движок для запуска ИИ-моделей локально | «мозг» |
| Модель qwen3.5:2b | стартовая модель, ~1.5 ГБ | чтобы чат работал сразу |
| Приложение OpenJarvis | окно с чатом, трей, автообновление | интерфейс |

Всё ставится в папку пользователя (`%LOCALAPPDATA%\OpenJarvis`), кроме Build Tools и Git — они общесистемные.

## Как пользоваться

- **Ярлык «Jarvis»** на рабочем столе — открыть окно.
- Jarvis **стартует вместе с Windows** и живёт в трее (рядом с часами). Правый клик по иконке → Show / Hide.
- **Консоль** (для проверки и настроек): откройте PowerShell и введите `jarvis`.
  Полезные команды: `jarvis doctor` (диагностика), `jarvis model list` (модели), `jarvis self-update` (обновить).

## Голос

Сейчас в OpenJarvis есть режим `jarvis chat --voice`: говорите в микрофон, он распознаёт речь
(Whisper, русский понимает) и отвечает голосом. **Слова-активатора «Джарвис» пока нет** — это следующий
шаг, который мы добавим отдельно (готовая модель распознавания «Hey Jarvis» существует, её нужно подключить).
Русский голос для ответов тоже настроим отдельно: встроенный синтезатор Kokoro русский не озвучивает.

## Удалить

```powershell
# в PowerShell
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'OpenJarvis' -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\OpenJarvis"
```

Плюс «Установка и удаление программ» → OpenJarvis, Ollama (модели лежат в `%USERPROFILE%\.ollama`).
Build Tools, Git, Python и Rust можно оставить — они пригодятся и другим программам.

## Если не получилось

Журнал установки: `%LOCALAPPDATA%\OpenJarvis\logs\install-<дата>.log`. Пришлите его мне — разберёмся.

Частые случаи:

- **«Не найден winget»** — установите «Установщик приложения» из Microsoft Store и запустите снова.
- **Build Tools не встали** — поставьте вручную: https://aka.ms/vs/17/release/vs_BuildTools.exe,
  отметьте «Разработка классических приложений на C++», затем снова `.bat`.
- **Чат не отвечает** — в PowerShell: `jarvis doctor`. Обычно ещё качается модель.
- **Порт 8000 занят** — закройте программу, которая его использует, или перезагрузите ПК.
